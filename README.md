# 🐍 Curso de Python - Fundamentos

## 📌 Descripción

Este repositorio contiene el material y los ejercicios prácticos desarrollados durante un curso de fundamentos de Python. Cada notebook corresponde a una sesión del curso, en la que se abordan progresivamente los conceptos básicos y esenciales del lenguaje, con el objetivo de construir una base sólida para quienes se están iniciando en la programación con Python.

Los notebooks fueron creados y trabajados en **Google Colab**, por lo que incluyen tanto teoría como ejemplos de código ejecutables.

## 📂 Contenido del repositorio

| Archivo | Descripción |
|---|---|
| `Sesión_1_Python_Fundamentals.ipynb` | Introducción a Python: sintaxis básica, variables y tipos de datos. |
| `Sesión_2_Python_Fundamentals.ipynb` | Estructuras de control: condicionales y bucles. |
| `Sesión_3_Python_Fundamentals.ipynb` | Estructuras de datos: listas, tuplas, diccionarios y sets. |
| `Sesión_4_Python_Fundamentals.ipynb` | Funciones y buenas prácticas de programación. |

> 📝 *Nota: puedes ajustar la descripción de cada sesión según el contenido real que hayas trabajado en cada notebook.*

## 🚀 ¿Cómo usarlo?

Existen dos formas principales de utilizar este repositorio:

### Opción 1: Abrir directamente en Google Colab
1. Ingresa al notebook que desees revisar (por ejemplo, `Sesión_1_Python_Fundamentals.ipynb`).
2. Haz clic en el botón **"Open in Colab"** (si está disponible) o copia la URL del notebook.
3. Pégala en [Google Colab](https://colab.research.google.com/) para ejecutarlo directamente en la nube, sin necesidad de instalar nada.

### Opción 2: Clonar el repositorio y ejecutarlo localmente
```bash
# Clona el repositorio
git clone https://github.com/tu-usuario/curso_python.git

# Ingresa a la carpeta del proyecto
cd curso_python

# Instala Jupyter Notebook (si no lo tienes)
pip install notebook

# Ejecuta Jupyter Notebook
jupyter notebook
```
Luego abre el archivo `.ipynb` de la sesión que desees revisar.
